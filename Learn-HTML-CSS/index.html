Block Elements

These are the Block Elements of HTML.

Tag Name

<address>

Description

Defines contact information for the author or owner of a document.

Syntax


<address>
    Farhan 
    Gopalganj 
</address>

Output

Farhan
Gopalganj

<article>

Description

</article>

This is an article.
