# 📘 HTML Tags Handbook

A simple and beginner-friendly HTML handbook that demonstrates the most commonly used **Block Elements** and **Inline Elements** with clear explanations, syntax, and live examples.

I built this project while learning HTML to better understand how different tags work. Instead of only reading theory, this project shows the actual output of each tag, making it easier to learn and revise HTML fundamentals.

---

## 🚀 Features

- 📚 Covers Block and Inline HTML Elements
- 📝 Short description for every tag
- 💻 Syntax example for each tag
- 👀 Live output demonstration
- 🎨 Clean and responsive UI using CSS
- 📖 Beginner-friendly layout
- 🌐 Easy to understand and navigate

---

## 🎯 Purpose

The main goal of this project is to provide a practical reference for learning HTML. Each tag includes:

- Tag Name
- Description
- Syntax
- Live Output

This makes it useful for:
- Beginners learning HTML
- Students preparing for exams
- Quick HTML revision
- Practice and experimentation

---

## 📸 Preview

The project displays each HTML tag inside a styled card containing:

- 📌 Tag Name
- 📝 Description
- 💻 Syntax
- 👀 Live Output

This layout makes learning HTML more interactive and easier to understand.
